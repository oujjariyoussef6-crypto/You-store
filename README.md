# 🔥 "Shut Up" T-Shirt Logo Design

A dark, edgy t-shirt logo featuring gothic/grunge aesthetics with powerful, intimidating vibes.

## 🎨 Design Features

- **Style**: Gothic/Grunge with distressed effects
- **Color Scheme**: Black and White (high contrast)
- **Typography**: Bold, impactful gothic-style lettering
- **Elements**: 
  - Subtle skull silhouettes in background
  - Flame accents for intensity
  - Grunge texture overlays
  - Distressed edges and rough filters
  - Drop shadows for depth

## 📁 Files Included

- `shut-up-logo.svg` - Main logo file (scalable vector format)
- `preview.html` - Interactive preview with multiple backgrounds and t-shirt mockup

## 🖼️ Viewing the Design

Open `preview.html` in your web browser to see:
- Logo on different backgrounds (black, dark gray, white)
- T-shirt mockup visualization
- Design specifications and features

## 💡 Usage Instructions

### For T-Shirt Printing:

1. **Direct-to-Garment (DTG) Printing**:
   - Use the SVG file directly or convert to high-res PNG (300 DPI minimum)
   - Recommended print size: 10-12 inches wide
   - Works best on black or dark-colored shirts

2. **Screen Printing**:
   - Convert SVG to vector format compatible with your printer
   - Two-color design (black and white) makes it cost-effective
   - High contrast ensures crisp prints

3. **Heat Transfer**:
   - Export as high-resolution PNG with transparent background
   - Ensure white elements are opaque for proper transfer

### File Conversion:

The SVG format is scalable and can be:
- Opened in Adobe Illustrator, Inkscape, or any vector editor
- Converted to PNG at any resolution without quality loss
- Modified or customized as needed

## 🎯 Best Practices

- **Shirt Color**: Works best on black, dark gray, or navy shirts
- **Print Size**: 10-12 inches wide for standard adult t-shirts
- **Placement**: Center chest placement recommended
- **Material**: Cotton or cotton-blend fabrics for best results

## 🛠️ Customization

The SVG file can be easily customized:
- Change colors by editing fill/stroke attributes
- Adjust text size or spacing
- Modify opacity of skull/flame elements
- Add additional effects or elements

## 📐 Technical Specifications

- **Format**: SVG (Scalable Vector Graphics)
- **Dimensions**: 800x800px (scalable to any size)
- **Color Mode**: RGB (convert to CMYK for professional printing)
- **Transparency**: Transparent background (print-ready)
