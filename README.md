# 🔥 "SHUT UP" T-Shirt Logo Design

A dark, edgy, and intimidating t-shirt logo featuring gothic/grunge aesthetics with bold typography, subtle skull elements, and flame accents.

## 🎨 Design Features

- **Style**: Dark, edgy, gothic/grunge aesthetic
- **Colors**: High-contrast black and white
- **Typography**: Heavy impact font with white stroke outline
- **Elements**: 
  - Subtle skull motifs in background
  - Flame accents at bottom
  - Distressed border frame
  - Grunge texture overlay
  - Shadow effects for depth
  - Decorative corner elements

## 📁 Files Included

- `shut-up-logo.svg` - Main logo file (scalable vector graphics)
- `preview.html` - Interactive preview showing the logo on different backgrounds
- `README.md` - This file

## 🚀 Quick Start

1. **View the Design**: Open `preview.html` in your web browser to see the logo on different backgrounds
2. **Download**: The SVG file is ready for printing
3. **Print**: Send `shut-up-logo.svg` to your t-shirt printer

## 🖨️ Printing Recommendations

### Print Specifications
- **Format**: SVG (vector - scales to any size without quality loss)
- **Recommended Size**: 10-12 inches wide on chest
- **Best T-Shirt Colors**: Black, dark gray, white, or any solid color
- **Print Methods**: 
  - Screen printing (best for bulk orders)
  - DTG (Direct-to-Garment) for single prints
  - Heat transfer vinyl

### Print Settings
- **Resolution**: Vector format - infinite resolution
- **Color Mode**: Black and white (2-color design)
- **Placement**: Center chest or large back print
